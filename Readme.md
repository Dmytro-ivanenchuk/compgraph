# Лабораторна робота №1 — Лінійні перетворення

Моделювання плоскої деталі з евклідовими, афінними та проективними перетвореннями. Інтерфейс на tkinter, сторонніх залежностей немає.

## Запуск

```
python main.py
```

Потрібен Python 3.8+ з tkinter (на Linux: `sudo apt install python3-tk`).

## Структура

```
main.py                 інтерфейс і рендеринг
core/
  point.py              точка P = [x, y, 1]
  matrix.py             матриця 3x3 та види перетворень
  transformations.py    фабрика перетворень за пунктами завдання
scene/
  primitives.py         відрізок, дуга, коло, еліптична дуга
  axes.py               осі та сітка
  model.py              деталь та її параметри
  scene.py              сцена: деталь + осі, ланцюжок перетворень
```

## Керування

| Дія | Як |
|---|---|
| Задати центр C (обертання, симетрія) | ліва кнопка миші |
| Панорамування | права (або середня) кнопка + рух |
| Масштаб | колесо миші (навколо курсора) |
| Повернути початковий вигляд | кнопка «Вмістити» |

## Можливості

- **Розміри** — повзунки для параметрів деталі, сусідні елементи з'єднуються автоматично.
- **Евклідові** — зсув, обертання навколо довільної точки C.
- **Афінні** — симетрія відносно C, масштабування (відносно початку координат), загальне афінне перетворення через O, X, Y.
- **Проективні** — через кінці осей, початок координат та ваги wx, wy, w0.
- Поточні матриці деталі та системи координат показуються в панелі.

## Як діють перетворення

- Зсув, обертання, симетрія, масштабування змінюють лише **деталь** (`model_local_transform`).
- Афінне та проективне змінюють **систему координат**, тобто сітку, осі й деталь разом (`world_transform`).

Ланцюжок для точки деталі: `модель → локальна → світова → вид (пікселі)`.

## Примітка

Якщо пряма `w' = 0` перетинає сцену при проективному перетворенні, лінії можуть відображатися некоректно. Обирайте ваги так, щоб вона не проходила через деталь.
