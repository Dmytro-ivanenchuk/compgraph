# Лабораторна робота №2 — Строфоїда (варіант 5)

Побудова та дослідження чудової кривої. Інтерфейс на tkinter, сторонніх залежностей немає.

## Запуск

```
python main.py
```

Потрібен Python 3.8+ з tkinter (на Linux: `sudo apt install python3-tk`).

## Крива

Права строфоїда, один статичний параметр `a`:

```
y² = x²(a + x)/(a − x)
x = a(t² − 1)/(t² + 1),  y = t·x,  t = tg φ,  −π/2 < φ < π/2
r = −a·cos 2φ / cos φ                       (полярний запис)
```

Вузол у початку координат, петля між вузлом і вершиною (−a, 0), вертикальна асимптота `x = a`.

## Структура

```
main.py                      точка входу
core/                        точка та матриця 3x3 (з лабораторної №1)
curves/                      математика (не знає ні про сцену, ні про tkinter)
  base.py                      Curve (ABC): спільна поведінка будь-якої кривої
  strophoid.py                 Strophoid(Curve): рівняння, похідні, особливості
  sampler.py                   CurveSampler: кеш вибірок точок
  numeric.py                   інтегрування (Сімпсон)
scene/
  curve_scene.py             CurveScene: стан (крива, точка, дуга, центр C, матриця)
services/                    прикладна логіка (без tkinter)
  report.py                    CalculationReport: текст розрахунків
  animator.py                  Animator: зміна a між мін і макс
  errors.py                    ValidationError
view/                        малювання (tkinter Canvas, без логіки кнопок)
  viewport.py                  Viewport: зум, панорама, світ <-> екран
  grid_renderer.py             GridRenderer: сітка, осі, цифри
  scene_renderer.py            SceneRenderer: крива, дотична, нормаль, ...
  drawing.py                   відсікання відрізків, ламана
  options.py                   DisplayOptions: що показувати
  theme.py                     кольори, шрифти
ui/                          вікно та елементи керування
  app.py                       App: збирає все докупи
  canvas_view.py               CanvasView: миша + запуск рендерерів
  forms.py                     NumberForm, action_button
  panels/
    base.py                      Panel, Callbacks
    curve_panel.py               вкладка «Крива»
    transform_panel.py           вкладка «Перетворення»
    animation_panel.py           вкладка «Анімація»
    info_panel.py                панель «Розрахунки»
```

Залежності йдуть в один бік: `ui → view → scene → curves → core`; `services` залежать від `scene` і `curves`. Пакети `curves`, `scene`, `services` можна запускати та тестувати без tkinter.

## Принципи ООП, які тут застосовано

- **Єдина відповідальність.** Кожен клас робить одне: `Viewport` знає лише про зум і координати, `GridRenderer` малює сітку, `Animator` рахує кадри, `CalculationReport` формує текст, `CurveScene` зберігає стан.
- **Абстракція та наслідування.** `Curve` — абстрактний клас: заданий через `@abstractmethod` мінімум (`point_t`, `d1`, `d2`, `phi_to_t`, `dt_dphi`, `equations`), решта (дотична, кривина, довжина дуги, перегини) успадковується. Необов'язкові особливості (`loop_range`, `vertical_asymptotes`, `areas`) мають порожні типові реалізації.
- **Відкритість до розширення.** Нова крива — це новий файл-наслідник `Curve`. Сцена, рендерери, звіт і панелі не змінюються.
- **Інверсія залежностей.** `CurveScene`, рендерери та звіт працюють з абстракцією `Curve`, а не з `Strophoid`. Конкретну криву вибирає лише `ui/app.py`.
- **Композиція.** `App` складається з панелей і полотна, полотно — з `Viewport` та рендерерів. Панелі не знають одна про одну й спілкуються із застосунком через `Callbacks`.
- **Інкапсуляція.** Кеш точок прихований у `CurveSampler`, поточний вигляд — у `Viewport`, стан сцени змінюється лише її методами.

## Як додати нову криву

1. Створіть `curves/my_curve.py` з класом-наслідником `Curve` і реалізуйте абстрактні методи.
2. За потреби перевизначте `loop_range`, `vertical_asymptotes`, `areas`, `notes`; якщо координати пропорційні `a`, поставте `LINEAR_IN_A = True` (тоді точки кешуються).
3. У `ui/app.py` замініть `Strophoid(2.0)` на свій клас.

## Керування

| Дія | Як |
|---|---|
| Центр обертання C | ліва кнопка миші |
| Панорамування | права (або середня) кнопка + рух |
| Масштаб | колесо миші |

## Що обчислюється

- рівняння дотичної й нормалі у вибраній точці та асимптоти (після перетворень);
- радіус кривини та коло кривини;
- довжина петлі та довільної дуги `[φ₁; φ₂]` (інтеграл Сімпсона);
- площа петлі `a²(2 − π/2)` та площа між кривою й асимптотою `a²(2 + π/2)`;
- точки перегину: **немає**, бо `x'y'' − y'x'' = 4a²(3t² + 1)/(t² + 1)³ > 0`.

Довжина всієї кривої нескінченна, тому рахується довжина петлі та заданої дуги.

Евклідові перетворення (зсув, обертання навколо C) застосовуються до всіх об'єктів разом: кривої, дотичної, нормалі, асимптоти, кола кривини.
